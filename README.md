# Team Member Showcase | HTML & CSS

My third CSS capstone project, featuring a responsive team member showcase for a fictional music record label.

This project was built using HTML and CSS to practice creating professional profile cards, responsive layouts, and interactive hover effects.

## About the Project

The Team Member Showcase is a fictional music record label website section that introduces six members of its leadership team.

Each profile card displays a team member's name, position, profile image, description, and social media icons.

The page also includes a recruitment section encouraging musicians to submit their music.

## Features

- Six team member profile cards
- Responsive CSS Grid layout
- Flexbox alignment and spacing
- Circular profile images
- Social media icons using Font Awesome
- Hover animations on cards, icons, and buttons
- Custom CSS variables for consistent styling
- Dark-themed interface with turquoise and orange accents
- Recruitment call-to-action section
- Mobile-friendly design

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- CSS Flexbox
- CSS Media Queries
- CSS Custom Properties
- Font Awesome Icons
- Google Fonts

## Responsive Design

The layout adjusts to different screen sizes:

| Screen Size | Layout |
|---|---|
| Desktop | 3 columns |
| Tablet | 2 columns |
| Mobile | 1 column |

Additional media queries adjust typography, spacing, card dimensions, and images for smaller screens.

## What I Practiced

While building this project, I practiced:

1. Using CSS Grid to organize multiple cards.
2. Using Flexbox to align content inside cards.
3. Positioning profile images with absolute and relative positioning.
4. Creating hover effects with CSS transitions and transforms.
5. Using CSS variables to manage colors and styling.
6. Writing media queries for responsive layouts.
7. Building reusable card components with consistent styling.
8. Organizing HTML and CSS into separate files.

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.

No installation or build tools are required.

An internet connection is needed to load external profile images, fonts, and icons.

## Project Notes

This is a fictional music record label concept created for frontend development practice.

The team member names are used for demonstration purposes. The profile images are placeholders and do not represent the named individuals. The social media icons and submission button are visual UI elements and are not connected to functional destinations.
